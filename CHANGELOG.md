# Changelog

## 0.2.0 — 2026-10-17

- Reoriented the application around offline mix/reference comparison.
- Added whole-file and independent passage analysis.
- Added libebur128 loudness, LRA and true-peak measurement.
- Added tonal and stereo band comparisons, descriptive summaries and graphs.
- Added A/B playback with optional attenuation-only loudness matching.
- Added Markdown report export and project documentation.
- Replaced the REAPER stem/action workflow with a master-render handoff.
- Removed correction FX from the installer payload.

## Earlier prototype

Explored stem relationships, technical mix advice and applying corrections in
REAPER. That workflow is no longer exposed by the application or bridge.
